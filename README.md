# FinDash (demo)

Live demo of **FinDash**, a personal finance analyser, using 12 months of
synthetic/dummy transaction data — no real bank data involved.

**▶️ Open the demo: https://ankit768-thor.github.io/findash-demo/**

The full app runs locally on your own machine, reads your real bank
statements (CSV/XLS/PDF), de-duplicates and categorises transactions, and
serves an interactive dashboard — nothing leaves your computer. This repo is
a static snapshot of that dashboard's UI, pre-rendered against dummy data for
preview purposes. "Add statement" and other editing actions are disabled here
since there's no backend on GitHub Pages.
